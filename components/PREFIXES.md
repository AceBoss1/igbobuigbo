# IBI Platform — Reference Code Prefixes (Appendix)

All transaction, document, and identity references used across the
Igbo Bu Igbo platform. Every reference below is verifiable at
**https://igbobuigbo.org.ng/verify**

---

## 6. Verify Portal — Detection Logic

The `/verify` page auto-detects reference type by prefix:

```
IBI-STMT-*       → Wallet Statement   (needs Auth Key param)
IBI-UPG-*        → Membership Upgrade (Paystack)
IBI-UPG-WLT-*   → Membership Upgrade (Wallet)
IBI-AFF-*        → Affiliate Commission
IBI-BONUS-*      → Bonus Credit
ADMIN-*          → Admin Adjustment
IBI-TRF-* / TRF-* / IBI-WLT-* / IBI-CARD-* → Transaction
IBI-WYB-*        → Parcel Tracking
CARD-*           → Card Issuance
[A-Z]+/\d{10}   → Member Identity Card
```

---

## 7. Naming Conventions

- **Timestamps** use `Date.now()` (milliseconds since Unix epoch) — globally unique
- **Alphanumeric** suffixes (e.g. `TRF-MQMS6JV1`) are generated server-side using Firestore auto-IDs or random base-36 strings
- **No slashes** in any reference except Member IBI Numbers (`ANA/8263354454`) — slashes are URL-encoded as `%2F` where needed
- All references are **case-insensitive** in the verify portal (uppercased before matching)
- References are **stored as-is** in Firestore and **never modified** after creation

---

## 8. Paystack Configuration

All Paystack references must use a known prefix so the platform can:
1. Route the verify portal lookup to the correct Firestore collection
2. Match the payment to the correct member action on webhook/callback

**Do not** use generic refs like `pay-12345` — always use the prefix table above.
